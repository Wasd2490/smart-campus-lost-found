# 更新日志

## v1.0.0 - 2026-10-10

### 新增功能
- 用户注册/登录/退出（Cookie会话）
- 注册字段：用户名、密码、真实姓名、学号、学院、班级、手机号
- 失物登记发布（支持拍照上传照片）
- 招领通知发布（支持拍照上传照片）
- 物品首页列表（双Tab切换寻物/招领）
- 关键词搜索
- 物品详情页（描述、照片、地点时间、联系方式）
- 物品评论区（朋友圈样式）
- 申请认领（填写物品特征）
- 领取确认（下拉选物品，标记已找回）
- 我的记录（我发布的、我认领的）
- 管理员后台（审核物品、处理认领、用户列表）
- 响应式移动端适配
- ngrok 内网穿透支持外网访问

### 技术栈
- 前端：原生 HTML/CSS/JavaScript
- 后端：Python http.server（无框架）
- 数据库：MySQL（5张表）
- 会话：Cookie SESSION_ID

### 数据库表
- users（用户表）
- lost_items（失物登记表）
- found_items（招领信息表）
- claim_records（认领记录表）
- comments（评论表）
